# Skills

Agent skills. Each one is a text file your coding agent reads.

## consumer-idea-lab

A method for finding consumer app ideas people open every day. It generates ideas, runs five filters, researches the survivors and ends each one with a yes, maybe or no.

Install:

```
npx skills add dashelvoskuhl/skills
```

Then ask your agent:

```
Run the idea lab on this: <your idea>
```

Example run: [DoorDash, judged as of January 2013](examples/doordash.md). The method says maybe, and the example covers why it under-called a winner.
